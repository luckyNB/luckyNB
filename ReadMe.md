# 💫 About Me:
### About Me<br><br>Hi, I'm Laxman — a Senior Quality Analyst with 6+ years of experience in Quality Engineering, working across Web, Mobile, and API applications.<br><br>I enjoy exploring how applications work, finding what could go wrong, and making sure software delivers a reliable experience to its users. My work involves a mix of manual testing, automation, API validation, and collaborating with developers and business teams to improve overall product quality.<br><br>**What I work with:**<br>- **Web Automation:** Selenium WebDriver, WebdriverIO, Cypress<br>- **Mobile Automation:** Appium, Espresso, XCUITest<br>- **API Testing:** Postman, Insomnia, Rest Assured, SuperTest<br>- **Programming:** Java, JavaScript, TypeScript, Swift<br>- **Frameworks & Tools:** TestNG, JUnit, Maven, Jenkins, GitHub Actions<br>- **Performance Testing:** JMeter, k6<br><br>I'm also exploring how AI can make QA more effective, using tools like GitHub Copilot and Claude for test-case generation, automation scripting, debugging, and identifying edge cases.<br><br>I believe quality is not just about finding bugs; it's about preventing them, asking the right questions, and building confidence in every release.<br><br>Always curious, always learning, and always looking for better ways to test and build quality software.
